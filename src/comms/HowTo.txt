************************************************************************************************************
How to convert mp3-files into caff-files (CoreAudio File Format) in macOS Terminal using "afconvert" utility
************************************************************************************************************
List of supported file/data formats:
% afconvert -hf
All mp3-files into caf/IMA4:1/44kHz/Mono:
% for i in *.mp3; do afconvert -f caff -d ima4@44100 -c 1 $i; done
All mp3-files into wav/little-endian signed 16-bit integer linear PCM/44kHz/Mono:
% for i in *.mp3; do afconvert -f WAVE -d LEI16@44100 -c 1 $i; done

// Sign "Developer ID Application" and notarize (macOS 10.15.4 Catalina, Xcode 11.4)
//----------------------------------------------------------------------------------
1. Xcode > Preferences... > Accounts > + > AppleID > ... > Manage Certificates... > + > Developer ID Application
   (or manually using site developer.apple.com > Account > Certificates, IDs & Profiles > macOS > Mac Development, Developer ID Application > Download)
2. Project navigator > PROJECT-NAME > TARGETS TARGET-NAME >
	Signing & Capabilities >
		[ ] Automatically manage signing
		Team = Andrii Shpahin
		Provisioning Profile = None
		Signing Certificate = Developer ID Application
	Build Settings >
		[Release] Code Signing Inject Base Entitlements = No (to solve notarization error "The executable requests the com.apple.security.get-task-allow entitlement.")
		[Release] Other Code Signing Flags = --timestamp (to solve notarization error "The signature does not include a secure timestamp.")
		[Release] Enable Hardened Runtime = Yes
		Note that "Hardened Runtime":
			A. Activates only on system with enabled SIP.
			B. Causes error in Xcode Console "Library not loaded: @rpath/xxx.dylib" when project is not signed.
			C. Causes "Message from debugger: Error 1" when "Code Signing Inject Base Entitlements = No"
			D. Prevents app from accessing third-party "3DconnexionClient.framework". To access do in Xcode:
			   File > New > File... > macOS > Resource/Property List > name "Entitlements.plist" >
			   --> [RMB] in editor area > Property List Type = [V] Entitlements File > (+) Disable Library Validation = YES
			   --> Project navigator > [PROJECT_NAME] > Build Settings > Code Signing Entitlements = Entitlements.plist
			   --> to check in Terminal: % codesign -d --entitlements :- /Applications/3DCoat-x.x.xx/3DCoat.app
3. Application specific password for "altool":
	https://appleid.apple.com/account/home > Security > APP-SPECIFIC PASSWORDS > Generate Password...
	(to view Security > Edit > APP-SPECIFIC PASSWORDS > View History)
4. Test APP:
	$ spctl -a -v XXX.app
	(the output should be: "XXX.app: accepted source=Developer ID")
5. Test DMG:
	$ spctl -a -t open --context context:primary-signature -v XXX.dmg
	(the output should be: "XXX.dmg: accepted source=Developer ID)
Error 1. The signature does not include a secure timestamp.
	% codesign -dvv ./3DCoat.app
	(if there is "Signed Time" then the binary has no secure timestamp, only when there is "Timestamp")
Error 2. The signature of the binary is invalid. It means that you make a modification after signing.
	To copy app-bundle use "rsync -a" (do not use "cp -r"). To check: % codesign -vvv --deep --strict ./3DCoat.app
Error 3. The executable requests the com.apple.security.get-task-allow entitlement. By default Xcode sets
	"Build Settings > Code Signing Inject Base Entitlements = Yes" to allow debugging (on systems with enabled SIP).
Error 4. The binary is not signed with a valid Developer ID certificate.
	Do step 2 for every target in the project.
Error 5. The executable does not have the hardened runtime enabled.
	Set "Build Settings > Enable Hardened Runtime = Yes" for every target in the project.

// How to build ZIP (http://zlib.net/) and PNG (http://www.libpng.org/) libraries
//*******************************************************************************
Windows 10 + Visual Studio 2017
	1. Extract "zlib1211.zip" and "lpng1636.zip" in the same folder (rename folder "zlib-1.2.11" into "zlib").
	2. Open "lpng1636\projects\vstudio\vstudio.sln". Uncheck and then "Solution Explorer > Unload Project" all except "zlib", "pnglibconf", and "libpng".
	3. Select configuration [Release Library, Win32].
	4. [LMB] "libpng" + [Ctrl + LMB] "zlib" > Properties > C/C++ > [Release Library] >
		Make sure that: Code Generation > Runtime Library = Multi-threaded (/MT)
		General > Debug Information Format = None (to solve "warning LNK4204: 'vc120.pdb' is missing debugging information for referencing module; linking object as if no debug info")
		Optimization > Whole Program Optimization = No (to solve problem "libpng16.lib(png.obj) : MSIL .netmodule or module compiled with /GL found; restarting link with /LTCG; add /LTCG to the link command line to improve linker performance")
		General > Treat Warnings As Errors = No (to solve "error C2220: warning treated as error - no 'object' file generated")
	5. zlib > Properties > C/C++ > Preprocessor > [Release Library] > Preprocessor Definitions > Remove "Z_SOLO" (otherwise functions "inflateInit2" and "deflateInit2" will return "Z_STREAM_ERROR")
	6. [RMB] zlib > Add > Existing Item... > gzclose.c + gzread.c + gzwrite.c + gzlib.c (these functions are used in "3DCoat" inside file "svg.c")
	7. [Release Library, Win32] > Build > Build Solution
	8. Build > Configuration Manager... > Active solution platform: <New...> / x64 / Select "Copy settings from: Win32" / Check "Create new project platforms".
	9. [Release Library, x64] > Build > Build Solution
	10. Copy "lpng1636\projects\vstudio\(x64\)Release Library\libpng16.lib + zlib.lib" into "Libs/Png/1.6.36/Windows/32(64)".
	11. Copy zlib\zlib.h + zconf.h, lpng1636\png.h + pnglibconf.h + pngconf.h into "Libs/Png/1.6.36/Windows".

//*****************************************************************************
// How to remotely debug on a tablet with Windows 8.1
//*****************************************************************************
1. On the tablet:
	1.1. Install "Tools for Visual Studio 2013 > Remote Tools for Visual Studio 2013":
	     https://www.visualstudio.com/downloads/download-visual-studio-vs
	1.2. Start > Remote Debugger
	1.3. Create folder "C:\WORK". Share it "Properties > Sharing > Share... > Share".
	1.4. Note pair {TABLET_NAME}\{USER_NAME} in the Control Panel > User Accounts > Configure advanced user profile properties (for example "RISYA\Marina")
2. On the host:
	2.1. File Explorer > Network > {TABLET_NAME} > Enter network credentials > Username = {TABLET_NAME}\{USER_NAME} (for example "RISYA\Marina"), Password = {YOUR_PASSWORD}
	2.2. Copy data into "\\Risya\WORK\"
	2.3. Visual Studio Express 2013 for Windows Desktop > Solution Explorer > YOUR_PROJECT > Properties > Configuration Properties >
		--> Debugging > Debugger to launch: Remote Windows Debugger >
			--> Remote Command = \\Risya\WORK\$(TargetFileName)
			--> Working Directory = \\Risya\WORK\
			--> Remote Server Name = RISYA:4018
		--> Build Events > Post-Build Event > Command Line = copy "$(TargetPath)" "\\Risya\WORK\" (copying is faster than deploying)
	2.4. Start project with button "[>] Remote Windows Debugger"
