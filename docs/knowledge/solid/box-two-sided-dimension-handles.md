# BOX: редактирование размера с двух сторон

Стартовая высота нового BOX выбирается по масштабу вида вместо фиксированных 5:
ориентир — 80 экранных пикселей с учётом проекции нормали. Для вида почти сверху
компенсация ракурса ограничена, чтобы не создавать чрезмерно высокий бокс.
Значение выбирается один раз после задания основания, ограничено диапазоном
0,001–900 и далее меняется только редактированием, а не движением камеры.

У каждого размера BOX две отдельные жёлтые заполненные стрелки.
Острия совпадают с концами размерной линии, треугольники располагаются внутри
измеряемого отрезка. Области захвата совмещены с треугольниками, без выноса наружу.
Перетаскивание дальнего конца изменяет размер при неподвижной базе.
Перетаскивание базового конца изменяет размер и сдвигает origin так,
чтобы противоположная плоскость оставалась неподвижной.

Для размера d вдоль единичной локальной оси a:
`origin_new = origin_old + a * (d_old - d_new)` для базовой стрелки.
Оси Length/Width/Height соответствуют axis.u/axis.v/axis.n.
Изменения размера и origin выполняются перед одним перестроением геометрии.
Стрелки разделены с размерной надписью; клик по надписи сохраняет числовой ввод.
Ширина и длина ограничены допустимыми положительными значениями, высота сохраняет
существующее редактирование со знаком и защитой от нулевого тела.

Отрисовка заполненных треугольников выполняется в OpenGL в экранных координатах,
с отключённым отсечением обратных сторон. QPainter polygons оказались невидимыми
в проверенном GL-режиме. Размер стрелок и области захвата не зависят от масштаба.
Остальные типы объектов сохраняют прежние ручки редактирования.

Проверки FacePrimitiveCut проверяют оба конца всех трёх размеров через UI-сигнал,
сохранение origin и противоположной плоскости, а также подтверждение операции.
Режим `--test-face-primitive-cut --render` сохраняет изображение и проверяет
наличие жёлтых стрелок в framebuffer.
