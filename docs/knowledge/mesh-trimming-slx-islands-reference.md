# Тримминг сетки: острова как эталон для SLX

Дата фиксации: 2026-08-26.

## Назначение случая

Этот пример служит эталоном для анализа и доработки:

```cpp
CMesh3D::TrimByPline(CPolyline* pLine, CPoint3d pc)
```

Метод островов на той же геометрии строит практически идеальную сетку, тогда
как SLX оставляет локально худшую топологию. Поэтому результат островов следует
использовать как ожидаемую топологическую цель, а не как реализацию, которой
можно незаметно заменить SLX.

## Условия воспроизведения

- Операция тела: `Boolean Cut`.
- Включено: `Mesh Quadro`.
- Плотность: `Density (normalized) = 0.50`.
- Сравниваются два запуска одной и той же модели:
  - `Mesh Quadro Hole SLX` выключен — метод островов;
  - `Mesh Quadro Hole SLX` включён — SLX и `TrimByPline`.
- Круглые Low Poly границы используют минимум 8 сегментов. Общая кромка
  синхронизируется с цилиндрической стенкой.

## Наблюдение

### Метод островов

Область между наружной границей поверхности и отверстием заранее делится на
четыре направленных простых патча. Каждый патч получает замкнутый контур без
отверстий и квадрангулируется отдельно.

Схема:

```text
              наружная граница
        +---------------------------+
        |            |              |
        |     верхний патч           |
        |        +---------+         |
        | левый  | отверстие| правый |
        | патч   +---------+  патч   |
        |        нижний патч         |
        |            |              |
        +---------------------------+
```

Результат:

- переход к отверстию регулярный;
- воротник сохраняется;
- нет необходимости внедрять контур в уже готовые крупные клетки;
- направление рядов предсказуемо;
- острова являются референсом для оценки результата SLX.

### SLX

SLX сначала строит одну сплошную фоновую сетку по наружному контуру поверхности:

```text
наружный контур поверхности
    -> ContourToFill
    -> ContourQuadrangulator
    -> сплошная фоновая Quadro-сетка
```

`TrimByPline` не участвует в построении наружной границы. После создания
фоновой сетки метод применяется только к внутренним вырезам. Внешнее кольцо
воротника при этом является внутренним контуром выреза: им создаётся окно,
затем сетка воротника добавляется в оставшуюся сетку и сваривается по шву.

В местах неудобного пересечения внутреннего контура выреза с готовыми ячейками
могут возникать лишние диагонали, треугольные веера или неправильная сторона
разреза.

Воротник внутри SLX обязателен и не должен автоматически заменять SLX методом
островов. Его задача:

```text
точный контур отверстия
    -> один или два переходных ряда
    -> внешний контур с шагом фоновой сетки
    -> TrimByPline
```

## Правила дальнейшей разработки

1. Наружный контур поверхности обрабатывается только конвейером
   `ContourToFill -> ContourQuadrangulator`; передавать его в `TrimByPline`
   запрещено.
2. `TrimByPline` применяется только к внутренним вырезам готовой базовой сетки.
3. Галочка `Mesh Quadro Hole SLX` всегда должна запускать ветку SLX.
4. Метод островов нельзя использовать как скрытый fallback для плохого SLX.
5. Воротник нельзя отключать для показа сырого дефекта: сравнение до и после
   доступно через диагностические OBJ.
6. Исправления должны выполняться в `TrimByPline` и его вариантах разрезания
   ячеек, если подготовленный внешний контур воротника уже корректен.
7. Удаление лишних диагоналей между двумя треугольниками является отдельным
   последующим cleanup-этапом и пока не должно маскировать ошибки резки.

## Диагностика

Для SLX сохраняются два файла в:

```text
C:\temp\Dom3D_Quadrangulation
```

- `Surface_<id>_SLX_StepMilli_<step>_BeforeHoles.obj` — исходная сплошная
  сетка перед первым вызовом `TrimByPline`;
- `Surface_<id>_SLX_StepMilli_<step>_AfterHoles.obj` — непосредственный
  результат после обработки отверстий.

## Критерии будущего исправления TrimByPline

- ни одна активная грань не находится внутри удаляемого отверстия;
- наружная сторона поверхности не теряется;
- каждое ребро используется не более чем двумя активными гранями;
- граница отверстия замкнута и совпадает с внутренним краем воротника;
- отсутствуют длинные треугольные веера через несколько фоновых клеток;
- при сопоставимых шагах результат не ухудшается;
- на этом примере топология SLX приближается к эталонному результату островов.
