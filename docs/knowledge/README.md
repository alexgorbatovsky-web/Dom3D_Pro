# Wiki Dom3D Pro

Это инженерная база знаний проекта. Она хранится рядом с исходным кодом, поэтому
выводы, тестовые случаи и принятые решения изменяются вместе с программой и не
зависят от истории отдельных обсуждений.

## Как пользоваться

- [Tile: восемь раскладок плитки из мешей](architecture-tile.md).

- Начинайте поиск с тематического указателя ниже.
- Статус в начале статьи показывает, насколько надёжен описанный вывод.
- Для нового исследования используйте [шаблон статьи](_template.md).
- Фраза **«Сохрани это в Wiki»** означает: оформить проверенные выводы, добавить
  ссылки на код и тесты и обновить это оглавление.

## Статусы статей

| Статус | Значение |
|---|---|
| `Гипотеза` | Наблюдение ещё требует воспроизведения или измерения. |
| `Исследуется` | Есть воспроизводимый случай, но причина или исправление не завершены. |
| `Проверено` | Вывод подтверждён тестом, диагностикой или повторяемым экспериментом. |
| `Внедрено` | Решение присутствует в коде и имеет проверку. |
| `Отложено` | Работа осознанно перенесена; причина указана в статье. |

Автоматические страницы строятся непосредственно из `src`, `tests` и
`CMakeLists.txt`:

```powershell
cmake --build build --target CodeWiki
```

Обычная цель `cmake --build build --config Release` собирает приложение, но не
перезаписывает Wiki.

## Локальная HTML-Wiki

Собрать страницы и открыть Wiki в браузере:

```powershell
cmake --build build --target OpenWiki --config Release
```

Только пересобрать HTML без открытия браузера:

```powershell
cmake --build build --target HtmlWiki --config Release
```

Локальный адрес после запуска: `http://127.0.0.1:8765/docs/wiki-html/`.

## Решения

- Наружный контур поверхности никогда не вырезается через `TrimByPline`.
  По нему сначала строится базовая Quadro-сетка конвейером
  `ContourToFill -> ContourQuadrangulator`; `TrimByPline` применяется только
  после этого и только для внутренних вырезов.
- В режиме Low Poly круглая граница отверстия строится минимум из восьми
  сегментов; общая OCCT-кромка синхронизирует её с цилиндрической стенкой.
- Полная сфера строится из шести квад-патчей куба по связности Catmull–Clark;
  UV-полюса и треугольные вееры не используются.
- Плоская грань с одной круглой или эллиптической границей строится методом
  `CapRetopo`, используя точное внешнее кольцо соседней криволинейной
  поверхности.
- Для грани с отверстиями включённый `Mesh Quadro Hole SLX` означает выполнение
  ветки SLX. Скрытая подмена методом островов запрещена. На грани без отверстий
  этот флаг не требует запуска SLX.
- Воротник является частью SLX, а удаление лишних диагоналей остаётся отдельным
  будущим этапом очистки топологии.
- Кольца воротника углового отверстия строятся из локальных направлений соседних
  сторон; радиальная привязка к общему центру для них запрещена.

Подробное обоснование этих решений приведено в статье
[об островах и SLX](mesh-trimming-slx-islands-reference.md).

## Диагностические материалы

SLX сохраняет промежуточные OBJ-файлы в
`C:\temp\Dom3D_Quadrangulation`:

- `*_BeforeHoles.obj` — фоновая сетка до первого вызова `TrimByPline`;
- `*_AfterHoles.obj` — сетка после обработки отверстий.

Это временные результаты запуска. Если файл становится эталонным примером, его
следует перенести в репозиторий вместе со статьёй, чтобы он не потерялся.
