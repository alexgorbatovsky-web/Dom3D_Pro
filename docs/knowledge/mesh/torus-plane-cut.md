# Torus: боковая сетка после обрезки плоскостью

Исходный файл из `Bags_Mesh/Torus.dom3d` сохранён без изменений как
`tests/data/mesh-regression/Torus_PlaneCut.dom3d`.
SHA256: `160D70370796F3802A76D7A6863E23BCAFA04006E79AEDBCF6C14402391DE5CC`.

Тело Torus состоит из двух тороидальных граней и двух плоских торцов.
При Density 0.50 прежнее заполнение оставляло на каждой боковой грани
лишь 9 квадов и один вырожденный треугольник у плоскости среза.
После сварки оставалось 66 открытых рёбер.

Граница тороидального UV-патча содержит два замкнутых поперечных контура
и две копии продольного шва. Заполнение оставшегося после удаления швов
контура превращало боковую поверхность в подобие торца.

Новый обработчик четырёхсторонней тороидальной полосы сохраняет оба
поперечных контура. Узлы упорядочиваются по периодическому V, между
согласованными узлами строятся ряды по U с вычислением точек на CAD-торе.
Граничные XYZ остаются общими с соседями; внутренние узлы проверяются
классификатором CAD-грани. Число рядов берётся из подготовленного продольного
ребра. Замкнутость сечения определяется по общей топологической вершине,
включая приближённые сплайновые кривые среза.

При Density 0.50 получаются 600 и 40 боковых квадов, без треугольников,
876 вершин после сварки, 0 открытых рёбер. Изображение:
`output/torus-cut/fixed-0.50-0.png`.

`TorusPlaneCutQuadro` проверяет Density 0.25, 0.50, 0.70, 1.00 и повторную
0.50: связность, отсутствие вырожденных клеток и перевёрнутых боковых квадов,
сохранение площади боковых поверхностей, длину их рёбер и замкнутость сварки.
Проверка площади относится к боковым граням: прежняя сетка плоского торца
на 0.25 занижает CAD-площадь примерно на 15%, этот алгоритм не изменялся.
Новый маршрут ограничен полосой с двумя согласованными замкнутыми сечениями;
произвольные отверстия в торе остаются на прежнем пути обработки.
