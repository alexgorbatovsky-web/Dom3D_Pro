# Mesh 3D — Image Relief / Рельеф по картинке

Mesh 3D → Relief («Рельеф по картинке») → щёлкните по одной грани тела или поверхности.
Инструмент включает выбор граней и открывает диалог для выбранной поверхности.
Можно предварительно выбрать одну грань. Выбор только целого тела недостаточен.
Загрузите PNG/JPEG/BMP/TIFF/WebP с развёрнутым орнаментом. Светлые пиксели
выступают наружу, чёрные оставляют поверхность без изменений. Прозрачные пиксели
не создают рельеф, в том числе при инверсии.

Задайте ось X/Y/Z, шаг сетки в миллиметрах, высоту рельефа, повторение по окружности
и высоте, поворот, начальную/конечную высоту в процентах и плавный переход у краёв.
Для поверхностей вращения ось проходит через центр габаритов Solid; этот режим
рассчитан на вазы и чаши вдоль мировой оси.

Для плоских граней (включая любую грань бокса и наклонные плоскости), сплайновых
и других невращательных поверхностей автоматически используется наложение по
собственным координатам поверхности U/V. Ось вазы отключена, повторы задаются
поперёк и вдоль поверхности. Проценты ограничивают область вдоль V; поворот
вращает картинку вокруг центра этой области. Высота откладывается по нормали.
Без сохранённых настроек используется один повтор поперёк поверхности.

Нажмите «1. Быстрый просмотр»: справа появится вращаемая грубая модель
(до 60 тысяч треугольников). Предпросмотр не добавляет объекты в документ.
После проверки нажмите «2. Построить итоговую сетку». Изменение параметров
или картинки сбрасывает предпросмотр и блокирует итоговое построение до его обновления.
Появится отдельный Mesh 3D всего тела; исходный Solid
можно автоматически скрыть. Операция поддерживает Undo/Redo. Отмена построения
и ошибки не изменяют документ. Для печати экспортируйте полученную сетку в STL.

Параметры автоматически запоминаются между открытиями и перезапусками программы,
включая закрытие через «Отмена»: шаг, высота рельефа, ось, оба повторения, поворот,
границы по высоте, затухание, инверсия, скрытие исходного тела, размер и положение
окна. Последняя успешно открытая картинка загружается повторно из её файла.
Если файл недоступен, числовые настройки сохраняются, но картинку нужно выбрать
заново. Выбранная грань и готовый предпросмотр не переносятся на другое тело.

## Геометрия

- Шаг означает максимальную длину ребра выбранной грани до рельефа.
  На резких перепадах картинки рёбра после смещения могут стать длиннее.
- Исходная CAD-геометрия и её экранная сетка не меняются: OpenCascade строит
  триангуляцию глубокой копии. Общие узлы граней свариваются, а общие рёбра
  подразделяются согласованно. Уплотняются рёбра выбранной грани; соседние грани
  подразделяются лишь у общих рёбер для сохранения связности. В итоговой сетке
  новые внутренние вершины проецируются на CAD-поверхность. Проектор поверхности
  переиспользуется для всех вершин. Грубый просмотр использует линейное подразделение.
- Узлы на границах разных CAD-граней интерполируются по хорде исходной
  триангуляции; отклонение задаётся начальной точностью (2,5% шага).
- Цилиндрическое наложение использует периодическую билинейную интерполяцию.
  Для повторяющегося рисунка лучше использовать бесшовную картинку.
- На невращательных поверхностях картинка заполняет прямоугольник UV-границ
  грани. На сложных сплайнах возможны растяжения; ширина затухания в миллиметрах
  оценивается по масштабу поверхности в центре. Обрезанные края и отверстия
  закреплены, но плавное затухание рассчитывается по границам UV-прямоугольника.
- Рельеф получает только выбранная грань. Её общие с соседями и открытые
  границы закреплены. Диапазон высоты в процентах относится к выбранной грани.
  Остальные грани не получают смещение. Высота неотрицательна: углубление стенки
  инструментом не предусмотрено.
- Проверяются замкнутость, ориентация стыков и локальные перевороты треугольников.
  Глобальный поиск самопересечений и проверка конкретного слайсера не выполняются.
  У сложных неосесимметричных тел возможны искажения наложения.
- Ограничение — 2 миллиона треугольников; при превышении нужно увеличить шаг.
- Открытая оболочка поддерживается и остаётся открытой; дно автоматически не добавляется.
- Расчёт выполняется в рабочем потоке. В окне прогресса показаны номер прохода,
  число треугольников и процент обработки рёбер в этом проходе (не общий процент
  всей операции). Отмена проверяется между порциями работы; текущий вызов CAD
  может потребовать времени на завершение.

Это преобразование яркости в высоту, а не автоматическая реконструкция листьев
по фотографии вазы: тени, блики и перспектива фотографии попадут в рельеф.

## Проверки

`ctest --test-dir build -C Release -R '^ImageRelief$' --output-on-failure`

Проверяется полая чаша: шаг сетки, замкнутые швы, внутренняя стенка, заданная
высота, защитные поля, инверсия, прозрачность, выбор оси, ограничения и отмена.

Дополнительно проверяются все шесть граней бокса (просмотр и итоговая сетка),
наклонная открытая плоскость, рисунок и его поворот, изогнутая поверхность Безье.
Проверяются высота, сохранение соседних граней и открытости оболочки.
