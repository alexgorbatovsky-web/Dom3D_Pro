# Фен: полная квадро-сетка через CAD boundary

Для тела `Imported STEP 4` из `Hairdryer.dom3d` экспериментальный потребитель
построил **85/85 граней**, **181 936 квадро-клеток**, **181 932 общие вершины**.
Проверены замкнутость собранного тела, сохранение ориентированной CAD-границы
и отсутствие перегиба клеток после перевода координат в float.

Готовый результат: [Hairdryer_Quadro.obj](../../../output/hairdryer-chart-fill/Hairdryer_Quadro.obj).
Обычная кнопка Mesh Quadro для фена пока не подключена к этому пути.
Вторая оболочка файла (283 грани) не входит в этот результат.

![Полная сетка](../assets/hairdryer-cad-chart-consumer.png)

## Почему оставались отказы

Одного общего набора граничных точек недостаточно. На составных противоположных
сторонах патча должны совпадать суммы чисел сегментов, а геометрические повороты
должны соответствовать друг другу по индексу. У узких полос F47/F58 одна сторона
состоит из двух CAD-рёбер, другая — из четырёх. Равномерный параметр сплайна и
даже одинаковое суммарное число точек не обеспечивали такое соответствие.
Периодический chart F51 дополнительно исключался из планирования из-за seam.

На F47 обнаружено также расхождение master XYZ с номинальной поверхностью:
максимальная нормальная дистанция около 0,000500 единицы модели. На очень узких
клетках фиксация границы на master, а внутренних узлов строго на поверхности
создавала пространственный перегиб при правильной UV-сетке.

## Реализованные изменения

- `PlanLogicalBoundary` сохраняет углы как CAD occurrence IDs и задаёт глобальные
  равенства чисел сегментов составных сторон. Ограниченный целочисленный решатель
  согласует их до заполнения граней, с точной проверкой полученных равенств.
- Для узких полос сопоставляются промежуточные CAD-вершины. Их проекции на
  противоположное ребро задают станции дискретизации; между станциями используется
  длина дуги. CAD-ребро не разрезается, identity сохраняется, обе соседние грани
  получают один master representation.
- Отдельные oriented occurrences периодического seam сохраняются в UV.
  Наличие seam само по себе больше не запрещает планирование прямоугольного chart.
- Помимо Coons используются локальные макропатчи: каждый треугольный макропатч
  разбивается на квадро-клетки с сохранением всех исходных граничных сегментов.
  Кандидаты проходят проверки UV, покрытия и пространственной геометрии.
- Для F47 применяется ограниченное плавное продолжение остатка `masterXYZ-S(UV)`
  внутрь полосы. CAD и его допуски не изменяются, граничные master XYZ фиксированы.
  Используется отдельный допуск аппроксимации сетки 0,01. Максимальное измеренное
  отклонение/смещение в этом проходе — 0,002351. Проверяются внутренние смещения,
  середины рёбер и центры двух треугольников каждой клетки. Это выборочная проверка
  погрешности, не доказанная глобальная оценка расстояния всей сетки от CAD.

Распределение принятых методов: cad-coons 50, planned-coons 16, triangle-patches 9,
surface-metric/dom3d 6, surface-metric/reference 2, logical-coons 1, tolerance-ruled 1.
Старые `FillContour.cpp` и основной quadrangulator на этом этапе не менялись.
CAD-топология снимается **один раз для тела**; изменение плана дискретизации
перестраивает подготовленные samples, но не вызывает повторный capture.

## Проверка и воспроизведение

Окончательная Release-сборка CatalogImportTests, QuadroBoundaryTests и Dom3D_Pro
успешна. Выбранные регрессии прошли **7/7**: QuadroBoundarySnapshot,
QuadroBodyBoundaryCache, PillowCadQuadro, HairdryerCadBoundary,
HairdryerCadChartConsumer, ToolsMesh3DFillContour, ExtrudeSlQuadro.
Проверка полного фена заняла 141,85 секунды. Исходный файл совпадает с fixture
по SHA256; пользовательская CAD-модель не изменялась.

`HairdryerCadChartConsumer` теперь требует все 85 граней. Прежнее ожидание
14 отказов удалено. OBJ записывается только после проверки целого тела,
ориентированных master-границ и геометрии в float. Сварка производится по
идентичности master node, а не по близости координат.

```powershell
CatalogImportTests.exe --diagnose-hairdryer-chart-fill tests/data/mesh-regression/Hairdryer.dom3d output/hairdryer-chart-fill
ctest --test-dir build -C Release -R HairdryerCadChartConsumer --output-on-failure
python tools/Visualize-QuadroChartFill.py output/hairdryer-chart-fill/report.json output/hairdryer-chart-fill/overview.svg
```

В `report.json` сохраняются source UV/XYZ, master IDs, принятые клетки, ошибки
попыток, логические углы и количества сегментов. `sampling-plan.json` содержит
равенства и нижние границы чисел сегментов; `boundary-fit.json` — расхождения
CAD-master и поверхности F47/F58. Полная история внутренних итераций старого
фронта не инструментирована.

Ограничения: результат пока плотный и экспериментальный; полная проверка занимает
около 140 секунд в текущей Release-сборке. Управление плотностью и подключение к
обычному UI остаются отдельным этапом. Успех этого тела не означает универсальной
поддержки произвольных CAD-моделей.
