# Procedural Fabric

В Material Editor нажать **Procedural Fabric…**, включить **Use Procedural
Fabric**. В списке Type / Preset доступны Linen (лён), Cotton (хлопок),
Twill (саржа) и Burlap (мешковина). Выбор пресета включает ткань и сбрасывает
параметры переплетения; цвет остаётся прежним. Готовые цветные материалы
находятся в библиотеке **Procedural**.

- Thread spacing — расстояние между нитями в миллиметрах.
- Thread width — заполнение шага нитью: меньшее значение даёт более открытое плетение.
- Scale — общий множитель размеров, шаг поля 0,01.
- Relief — выраженность рельефа нормалей, без изменения геометрии.
- Thread irregularity — неравномерность толщины и продольных утолщений нитей.
- Color variation — вариации цвета волокон; Base Color задаёт общий цвет.
- Roughness — шероховатость; Weave angle поворачивает переплетение.
- Seed — воспроизводимый рисунок вариаций.

Лён и хлопок используют полотняное переплетение; саржа — диагональное 2/2;
мешковина — редкое полотняное переплетение с крупными неровными нитями.
Они моделируют структуру поверхности ткани, а не складки или прозрачные
отверстия. При удалении камеры мелкие детали фильтруются, чтобы уменьшить муар.

Поле задано в координатах геометрии в миллиметрах, без UV. Три плоские
проекции смешиваются по нормали поверхности. На округлых участках направление
нитей плавно переходит между проекциями; для выкроек с точным направлением
нитей этот режим не предназначен. Перемещение вершин меняет участок поля.
Ткань и штукатурка выбираются как альтернативные источники одного материала.

`Material::fabric`, `DOM_FABRIC_PARAMETERS` и `FabricPreset` описывают
настройки; `ProceduralFabricShader.h` вычисляет цвет, нормали, шероховатость
и небольшое затемнение углублений. JSON version 1 хранится в XML-атрибуте
`proceduralFabric`; drag/drop version 7 также переносит его. Старые материалы
остаются без ткани. Миниатюры используют тот же шейдер и ключ кэша с параметрами.

Поддерживается интерактивный OpenGL-рендер. Экспорт PBR-карт ткани и нативное
процедурное вычисление во внешних/CPU-рендерах в эту реализацию не входят.

## Цветная ткань и обёртка подушки

Color texture теперь умножается на Base Color ткани; для исходных цветов
изображения задайте белый Base Color. Нормали нитей и шероховатость остаются
процедурными, прочие PBR-карты не подменяют их.

**Follow texture UV (color + weave)** переводит нити с пространственных
проекций на общие координаты цветовой текстуры. UV tile size задаёт размер
одного UV-повтора в миллиметрах; Scale продолжает менять размер нитей.

**Wrap whole object (seam underneath)** в основном разделе Textures вычисляет
единую азимутальную обёртку по габаритам всего тела, а не каждой CAD-поверхности.
Она непрерывна сверху и на боках, с искажениями и полюсом снизу. Предназначена
для выпуклых подушек, ориентированных верхом вдоль +Z. Перекрывает per-surface
Fit и смещения поверхностей; общие Scale U/V, Rotate и Offset работают.
Это настройка материала в рендере, сохраняемая в проекте и библиотеке,
а не изменение экспортируемых UV меша. При вращении геометрии обёртка
пересчитывается по её текущим габаритам.

Проверка: `CatalogImportTests --test-procedural-material --render`.
Изображения четырёх пресетов и диалога: `output/fabric`.
